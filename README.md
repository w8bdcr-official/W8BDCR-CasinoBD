# W8BDCR-CasinoBD

Super Ace slot game — Next.js web app with Firebase login, wallet, and admin panel.

## What it is

A slot game page (`web/`): spin with bet steps and multipliers, balance and wallet pages, Firebase auth, and admin routes for users, sessions, and wallet requests.

## Stack

Next.js 16, React 19, Firebase (auth + admin), JWT sessions.

## Run

```bash
cd web
npm install
npm run dev
```

Build with `npm run build`, start with `npm start`.
